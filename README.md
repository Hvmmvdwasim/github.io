# Zeera & Co. — Artisan Spice Merchants (Business Website)

A fictional Karachi-based spice trading business, built to demonstrate HTML, CSS and JavaScript fundamentals for a business website assignment.

## How to view
Unzip everything into one folder and open `index.html` in any browser — no server or build step required. All pages are linked relatively, so keep the `css/` and `js/` folders alongside the HTML files.

## Pages
- **index.html** — Home: hero image slider, trust marquee, featured products, "why choose us" cards, testimonial carousel, newsletter signup.
- **about.html** — About Us: brand story, values, milestones timeline, animated stats, team.
- **services.html** — Products: searchable/filterable product catalog, detail modal, WhatsApp-linked inquiry tray.
- **contact.html** — Contact Us: validated enquiry form, store hours, embedded Google Map, FAQ accordion.

## JavaScript features (js/script.js)
- DOM events: `DOMContentLoaded`, dynamic content injection, `IntersectionObserver` reveal/counter animations.
- Mouse events: nav toggle, filter pills, carousel arrows/dots, modal open/close, accordion, theme toggle, add-to-inquiry.
- Keyboard events: `Escape` closes the product modal, `keyup` powers live product search and the message character counter.
- Form validation: newsletter email format, and full contact-form validation (required fields, email/phone pattern, min message length) with inline error messages and a success state — no page reload.
- `localStorage` persists the light/dark theme choice between visits.

## Notes for the grader
- Product photography uses placeholder stock images (Lorem Picsum) since this is a fictional business — swap the `<img>` `src` attributes in the HTML for real product photos to go live.
- The WhatsApp number (+92 300 1234567) and Google Maps pin (Empress Market, Saddar) are placeholders — update them to a real number/address before deployment.
- Forms submit client-side only (no backend); replace the `submit` handler in `script.js` with a real API/email endpoint for production use.
